# README artwork

- `memfolder-hero.png` introduces the paper's two-stage idea. RecordFolder groups
  related memories; ContextFolder encodes the original records within those groups
  and uses verification feedback. Checkmarks are conceptual, not a guarantee of
  lossless compression.
- `memfolder-architecture.svg` describes the software interfaces. It is editable
  SVG source with an accessible description. Projection and feature refresh also
  occur between compression rounds; native materialization is the final output
  step. Gold labels enter only the Evaluator.

## Hero generation

The hero was generated with Codex's built-in native image-generation tool on
2026-10-08. Its interface did not expose a model identifier or quality-tier control,
so this asset does not assert an independently verified image-2 model version.
No other project's artwork was reused. See [the full prompt](hero-prompt.txt).

The source was visually reviewed for label accuracy, nine-to-three grouping,
three-group continuity, arrow direction, legibility and palette consistency.
The architecture SVG uses the same navy / teal / copper palette.
